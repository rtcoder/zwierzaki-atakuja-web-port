# Faithful 4× assets implementation plan

**Goal:** Preserve all original assets beside the project and refresh all 105 runtime images with a faithful, non-generative 4× upscale and gentle filtering, as selected by the user.

**Architecture:** `assets-original/` keeps byte-identical images and their original manifest outside the deployment directory. A reproducible Pillow script writes lossless PNGs into `dist/assets`, preserving logical dimensions in metadata while recording physical pixel dimensions and provenance. Canvas rendering uses logical destinations and scaled atlas source rectangles.

**Tech stack:** Python/Pillow for offline processing; existing JavaScript/Canvas runtime and Node tests. No new browser dependencies.

## Constraints and review focus

- Preserve poses, layout, transparency, colors, anchor positions and collision geometry.
- No generative AI; filtering cannot recover missing source detail.
- Process effect frames and font glyphs separately to prevent neighboring-frame bleed.
- Keep scenery spacing, grass tiling and eye overlays at their existing world sizes.
- Preserve original checksums; verify enhanced checksums, dimensions and renderer behavior.
