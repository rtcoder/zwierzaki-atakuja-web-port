# Zwierzaki Atakują Web Implementation Plan

> **For agentic workers:** Use the shared interfaces below; implement independent modules in parallel and integrate them in the owning task.

**Goal:** Build and publish a playable HTML/JS port using recovered original assets, level definitions and mechanics.

**Architecture:** A pure JavaScript simulation feeds a Canvas 2D renderer. DOM controls dispatch actions; browser storage saves progression. Original Java files remain analysis inputs outside the shipping site.

**Tech Stack:** HTML, CSS, JavaScript ES modules, Canvas 2D, Node built-in test runner.

**Spec:** `../specs/2026-10-25-web-port.md`

## Global constraints

- World Y increases downward; ground is Y=0.
- Original source is the authority for level positions, ammo and launch constants.
- No external runtime dependencies, phone messaging or legacy service requests.
- Preserve private hosting audience.
- Report unsupported mechanics and unverified parity.

## Review focus

- Repeated input must not consume two animals for one shot.
- Background tabs, dropped frames and resume must not produce an unbounded simulation jump.
- Touch dragging must not scroll the page while aiming, and pointer cancellation must release controls.
- Corrupt or unavailable localStorage must not prevent playing.
- Original levels with compounds, frozen axes or bosses must retain metadata and must not silently become unrelated layouts.

## Tasks

### 1. Recovered levels and assets

Files: `tools/extract-assets.py`, `tools/extract-levels.*`, `dist/js/assets.js`, `dist/js/levels.js`, `tests/levels.test.mjs`.

Interfaces: `LEVELS`, `LEVEL_COUNT`, `getLevel(id)`; body data includes `kind,x,y,angle,width,height,radius,vertices,mass,canTranslate,canRotate,material,isTarget,targetSize`. Compounds contain child shape specifications. Asset loader returns image objects keyed by original basename.

- [ ] Pin level one's recovered coordinates and three-skunk ammunition in tests.
- [ ] Extract original images and hash provenance; preserve actual image encodings.
- [ ] Record source level factory results without guessing geometry.
- [ ] Verify all shipped level IDs and image references.

### 2. Physics

Files: `dist/js/physics.js`, `tests/physics.test.mjs`, `docs/physics.md`.

Interfaces: `PhysicsWorld({gravity=200,iterations=10})`, `.add(spec)`, `.addGround(y=0)`, `.remove(body)`, `.step(dt=0.05)`, `.applyImpulse(body,ix,iy,px?,py?)`, `.bodies`. A step returns collisions with bodies, impulse, relative speed, point and normal.

- [ ] Test free fall, ground, frozen axes, angular response and shape contacts.
- [ ] Port body/collision equations with documented source correspondences.
- [ ] Verify finite state under repeated collisions and resting stacks.

### 3. Playable loop and persistence

Files: `dist/js/game.js`, `dist/js/storage.js`, `tests/game.test.mjs`, `tests/storage.test.mjs`.

- [ ] Pin shot velocity from the original angle and power formulas.
- [ ] Test one-shot input, ammo consumption, reset and outcome transitions.
- [ ] Implement aiming, launch, flight, special actions, damage, settling and progression.
- [ ] Test and implement versioned local save loading with malformed-data fallback.

### 4. Canvas presentation and controls

Files: `dist/index.html`, `dist/style.css`, `dist/js/renderer.js`, `dist/js/main.js`.

- [ ] Draw original world/animals/targets with scalable camera and clear HUD.
- [ ] Map mouse, touch and keyboard to actions with explicit capture/release.
- [ ] Handle resize, pause/resume, retry, overview and level selection.
- [ ] Verify playable browser flow and narrow viewport layout.

### 5. Ship and document

Files: `README.md`, `docs/port-status.md`, `tools/check-project.mjs`.

- [ ] Run full tests and check all shipped files.
- [ ] Review source and browser results; fix observed failures.
- [ ] Document what is verified and what is not.
- [ ] Push the exact source state and publish the private Site.
